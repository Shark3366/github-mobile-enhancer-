https://raw.githubusercontent.com/Shark3366/github-mobile-enhancer-/refs/heads/main/github-enhancer.user.js                                                                               # GitHub Mobile & Safari Enhancer (Safe Version) 📱🛠️

A lightweight, highly optimized Tampermonkey/Userscript that dramatically improves the GitHub browsing experience on mobile devices and Safari without breaking website layouts.

## ✨ Features

* **📱 Safe Mobile Optimization:** Automatically wraps long lines of code and scales code blocks beautifully on smaller screens without disrupting pop-ups, sidebars, or menus.
* **📋 Double-Tap to Copy:** Double-tap (or double-click) any code block to instantly copy its contents. Features a smooth, highly readable white-on-green visual flash for confirmation.
* **📂 Smart Auto-Expand PRs:** Automatically expands hidden "Load diff" buttons as you scroll through Pull Requests. Built with a safety guard to prevent infinite click loops on failed loads.
* **🔋 Battery Friendly:** Uses a lightweight `MutationObserver` targeted strictly at `document.body` instead of heavy interval loops, keeping your phone cool and saving processing power.

## 🚀 Installation

1. Install a userscript manager for your browser:
   * **iOS/Safari:** [Userscripts](https://apps.apple.com/us/app/userscripts/id1463298887) or [Tampermonkey](https://apps.apple.com/us/app/tampermonkey/id1482490089)
2. Click the link below to install the script directly:
   * 👉 **[Install the Userscript](PASTE_YOUR_RAW_URL_HERE)**
3. Tap **Install** or **Save** when your extension prompts you.
